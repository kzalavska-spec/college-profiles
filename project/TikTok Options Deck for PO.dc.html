BC-5787 · STUDENT CONNECT · COLLEGE PROFILE

Adding TikTok to the social component

THE ASK

Goals and requirements

Business goalIncrease engagement with premium profiles by showcasing TikTok alongside Instagram, so profiles feel richer and more current.
User goalStudents easily discover a school's TikTok, cohesive with Instagram and not visually overwhelming.
Success metricMore clicks/engagement with social media components on Student Connect profiles.
Requirements
TikTok mirrors the Instagram component
TikTok branding replaces Instagram branding
Not chunky or repetitive when both are enabled
Three states: Instagram only, TikTok only, both
Desktop and mobile web
Hidden if fewer than 3 posts or API error
DESIGN QUESTIONS
TikTok above or below Instagram?Below.Instagram is established and stays in place. Instagram-only profiles look exactly as today.
Too heavy to stack two components?Yes, at full size.Six large cards and two headers roughly double the section and push the next section down.
Combined "Socials" section?Yes, recommended.A switcher keeps today's footprint and treats both networks equally.
Mobile behavior?Swipe carousels.One row of cards at 80% width with dots. Never a vertical stack of six cards.
1

Combined, with switcher

One component in the Instagram slot. When both networks are connected, an Instagram | TikTok switcher swaps the account row and cards in place.

Pros
Same height as today's Instagram block
TikTok is an exact mirror of Instagram
Switcher only appears when both are connected
Cons
TikTok needs a click to be seen
Lower TikTok visibility may reduce its clicks
Desktop
Mobile

RECOMMENDATION

Option 1: combined, with switcher

Why
Only option that meets every layout requirement
Keeps today's section height on desktop and mobile
Instagram-only profiles stay unchanged
Clicks tracked per network and per tab
To improve TikTok discoverability
Default to the network with the most recent post
Hint on the inactive tab, e.g. "3 new videos"
A/B test Instagram vs. TikTok as the default tab
FallbackIf both must be visible without a click, use option 4.
